Help with Prism on iPhone and iPad.

Contact support

Email contact@operationembedded.net for help, purchase questions or privacy requests. Please include the details below so we can investigate.

Start here

  1. Open Browser options → Help & privacy → Browse formats and limits to check the file’s format and available tools.
  2. Import a local copy from Files. Files that are still downloading from a cloud provider must finish downloading first.
  3. For conversion, choose the file’s Convert action, select an output and find the result in My files → Exports. Share that copy to your destination app.
  4. If Pro is missing, use the same Apple Account and choose Restore Purchases from Prism Pro.

When reporting a problem

Include your Prism version, iPhone or iPad model, iOS/iPadOS version, file extension, the action you attempted and any error text. Don’t include private files, payment details or passwords. Share a small non-sensitive sample only if you intend to share it.

Known limits

Extensions do not guarantee every codec or file variant. Encrypted/DRM-protected files are unsupported. Video conversions support SDR up to 1080p and mono/stereo audio. Excel formulas are not recalculated, and macro-enabled/protected/signed workbooks are read-only. Check the in-app Format guide for further limits.
